# Oswój Kraków

Asystent AI dla nowych mieszkańców Krakowa. Odpowiada na pytania na podstawie oficjalnych danych miasta (karty usług BIP, Otwarte Dane Miasta Krakowa, MSIP, ZTP) i pokazuje wszystko na mapie — w tym „Kraków w 15 minut”: co jest dostępne pieszo lub komunikacją miejską od wskazanego adresu.

Projekt na konkurs **Open Data App 2026** (Gmina Miejska Kraków). Status: w budowie.
